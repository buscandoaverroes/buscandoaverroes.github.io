# Design Principles

1. Simplicity: beauty in simple colors, clean and clear design language
2. Adaptability: the website looks good in all modern browsers, on tablet, mobile and desktop. compatible with the browser/user's dark and light mode
3. accessability: users from any linguistic background should feel welcome to engage -- no overboard with text at the front, language toggles and, more importantly, a welcome aesthetic that transcends language. 
4. Reserved yet well though out: like the content, the design shouldn't say too much but should feel well crafted
5. Positive experience for user: the user should leave the site with a good impression whether spending just 3 seconds or 3 minutes on the site.
